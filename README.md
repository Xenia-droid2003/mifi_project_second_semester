# mifi_project_second_semester

Я разработала микросервис для инференса предсказательной ML-модели — лёгкое сервисное приложение на Flask, которое я спроектировала для бесшовной интеграции обученной модели случайного леса с внешними бизнес-системами по протоколу REST API. Чтобы упростить отладку и демонстрацию, я дополнительно встроила минималистичный веб-интерфейс: через него можно вручную отправлять одиночные векторные запросы и сразу визуально оценивать ответ модели.

Ниже — составленное мной пошаговое руководство по развёртыванию.

- Инициализация платформы
Чтобы изолировать все зависимости проекта и избежать конфликтов с системными библиотеками, я создаю виртуальную среду Python. Для этого в корневой папке микросервиса я выполняю команду:
python -m venv venv
После отработки команды появится директория venv/ с собственным интерпретатором и чистой экосистемой пакетов.

- Активация окружения
На хостах под управлением Windows я запускаю:
venv\Scripts\activate
На UNIX-подобных ОС (macOS / Linux) — команду:
source venv/bin/activate
При успешной активации в приглашении терминала появляется префикс (venv), сигнализирующий, что все последующие операции выполняются изолированно.

- Регистрация зависимостей
Я устанавливаю точный набор требуемых библиотек — прежде всего scikit-learn, pandas и Flask — в версиях, зафиксированных в файле requirements.txt. Это гарантирует воспроизводимость окружения:
pip install -r requirements.txt

- Подключение артефактов модели
Чтобы маршрутизация запросов к слою машинного обучения работала корректно, я помещаю заранее обученный и сериализованный пайплайн (бинарный файл model_rf.pkl) прямо в корень проекта. Если этот артефакт отсутствует, веб-сервер всё равно стартует, но API-эндпоинт предсказаний перейдёт в режим отказа и будет отвечать кодом 500 — в продакшен-среде такую ситуацию стоит исключить заранее.

Старт маршрутизатора
Я запускаю шлюз командой:
python app.py
После старта сервис становится доступен по адресу http://127.0.0.1:5000/. Стартовая страница отдаёт лёгкий клиентский интерфейс, который я подготовила для сквозной проверки инференса — он позволяет передавать параметры в виде JSON-массива и сразу видеть результат предсказания.
